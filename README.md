### 🏛️ Engineering & Architecture

My focus is on shipping resilient, high-framerate mobile products with zero backend bloat:

* **State & Concurrency:** Architecting declarative UI flows with Riverpod, ensuring strict separation of concerns, immutable state transitions, and 60–120 FPS render loops.
* **Data Layer & Security:** Designing PostgreSQL schemas with strict Row-Level Security (RLS) policies, database triggers, and RPC functions — moving data validation to the database layer rather than relying on vulnerable client checks.
* **Offline Resilience:** Building local-first caching strategies that keep data queryable and interfaces interactive under hostile 3G/rural connectivity conditions.
* **Native Tooling:** Integrating low-level Android package verification, background streaming, and GPS geofencing with custom platform channels.
